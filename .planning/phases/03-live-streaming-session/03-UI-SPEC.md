## Spacing Scale

Declared values (multiples of 4). Inherited from Phase 1 tailwind.config.js and constants/theme.ts:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, indicator padding |
| sm | 8px | Compact element spacing, pill badge internal padding |
| md | 16px | Default element spacing, HUD element margins |
| lg | 24px | Section padding, overlay edge insets |
| xl | 32px | Layout gaps, safe area offsets |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Touch targets: 56x56dp minimum for all interactive elements during session (UX-01, TOUCH_TARGETS.PRIMARY from constants/theme.ts)
- 44x44dp for secondary actions (TOUCH_TARGETS.SECONDARY)
- Safe area insets are dynamic (react-native-safe-area-context), not fixed spacing tokens

### Phase 3 Session Overlay Palette (new tokens)

The session screen uses a full-screen camera as the background. All UI overlays must be legible against any camera content. This requires a distinct overlay color set:

| Token | Value | Usage |
|-------|-------|-------|
| overlay-bg | rgba(0, 0, 0, 0.6) | Semi-transparent background for HUD containers, ensures WCAG AAA contrast for white text on any camera content |
| overlay-bg-light | rgba(0, 0, 0, 0.4) | Lighter overlay for less critical elements (status bar background) |
| overlay-text | #FFFFFF | All text rendered over camera feed |
| overlay-text-muted | rgba(255, 255, 255, 0.7) | Secondary text over camera feed |
| status-connected | #22C55E (green-500) | Traffic light "Connected" dot (D-15) |
| status-reconnecting | #F59E0B (amber-500) | Traffic light "Reconnecting..." dot (D-15) |
| status-lost | #EF4444 (red-500) | Traffic light "Connection lost" dot (D-15) |
| ai-indicator-bg | rgba(0, 0, 0, 0.7) | "AI" pill badge background (D-02) |
| ai-indicator-text | #FFFFFF | "AI" pill badge text (D-02) |

**Tailwind config extension required:**

```js
// Add to tailwind.config.js theme.extend.colors
"overlay-bg": "rgba(0, 0, 0, 0.6)",
"overlay-bg-light": "rgba(0, 0, 0, 0.4)",
"overlay-text": "#FFFFFF",
"overlay-text-muted": "rgba(255, 255, 255, 0.7)",
"status-connected": "#22C55E",
"status-reconnecting": "#F59E0B",
"status-lost": "#EF4444",
"ai-indicator-bg": "rgba(0, 0, 0, 0.7)",
```

Accent reserved for: "Start Session" CTA on Home screen, "I Understand" button on AI disclosure screen, "Start New Session" button on connection-lost state. Never used on the active session camera overlay.

## Interaction Contracts

### Session Start Flow (D-09, D-10, SESS-01)

| Step | Trigger | UI State | Duration |
|------|---------|----------|----------|
| 1. Tap "Start Session" | User tap on Home | Navigate to session route | Immediate |
| 2. Permission check | Route mounts | Loading spinner if permissions not yet granted; system permission dialog if needed | 0-3s |
| 3. AI Disclosure | Permissions granted | AI disclosure screen with "I Understand" button | Until user taps |
| 4. Camera-first connecting | User taps "I Understand" | Full-screen camera activates immediately. Top-right shows amber dot + "Connecting..." | 0-5s |
| 5. Session active | WebSocket connected | Green dot + "Connected". Audio indicator appears. Mic is hot. | Session duration |

### Session End Flow (D-11, D-12, SESS-09)

| Step | Trigger | UI State | Duration |
|------|---------|----------|----------|
| 1a. Tap stop | User taps stop button | EndSessionDialog appears: "End this session?" with "End Session" (destructive) + "Cancel" | Until user responds |
| 1b. Voice end | User says "end session" | AI confirms verbally: "Ending the session now. Goodbye." | 2-3s |
| 2. Session closes | User confirms or AI completes verbal | Camera stops, WebSocket closes, navigate to Home | Immediate |

### Reconnection Flow (D-13, D-14, SESS-08)

| Step | Trigger | UI State | Duration |
|------|---------|----------|----------|
| 1. Network drop | WebSocket closes unexpectedly | Camera stays live. Yellow dot + "Reconnecting..." with animated indicator. Audio pauses. | 0-120s |
| 2a. Reconnect success | WebSocket re-established | Green dot + "Connected". Audio resumes. | Immediate |
| 2b. Give-up timeout | 120 seconds of failed attempts | Red dot + "Connection lost". ConnectionLostOverlay appears with "Start New Session" button. | Terminal |

### Barge-In (D-07)

| Event | UI Response |
|-------|-------------|
| Technician starts speaking while AI is speaking | Audio indicator immediately switches from "AI speaking" waveform to "listening" static. All scheduled AI audio stops. No visual transition delay. |

## State-Driven UI Matrix

Maps Zustand session states to visual output:

| Session Status | Camera | AI Indicator | Connection Dot | Audio Indicator | Stop Button | Overlay |
|---------------|--------|-------------|----------------|-----------------|-------------|---------|
| idle | Off | Hidden | Hidden | Hidden | Hidden | None |
| requesting-permissions | Off | Hidden | Hidden | Hidden | Hidden | Loading spinner |
| disclosure | Off | Hidden | Hidden | Hidden | Hidden | AI disclosure modal |
| connecting | Live | Visible | Amber "Connecting..." | Hidden | Visible | None |
| active | Live | Visible | Green "Connected" | Visible (listening) | Visible | None |
| active + AI speaking | Live | Visible | Green "Connected" | Visible (waveform) | Visible | None |
| disconnected | Live | Visible | Yellow "Reconnecting..." | Hidden | Visible | None |
| reconnecting | Live | Visible | Yellow "Reconnecting..." | Hidden | Visible | None |
| failed | Frozen | Visible | Red "Connection lost" | Hidden | Hidden | ConnectionLostOverlay |
| timeout | Frozen | Visible | Red "Connection lost" | Hidden | Hidden | ConnectionLostOverlay |
| completed | Off | Hidden | Hidden | Hidden | Hidden | Navigate to Home |

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| UX-01: 56x56dp touch targets | Stop button: 56x56dp. All interactive elements use TOUCH_TARGETS.PRIMARY from constants/theme.ts. |
| UX-02: WCAG AAA contrast | White (#FFFFFF) on overlay-bg (rgba(0,0,0,0.6)) = contrast ratio 9.7:1 (exceeds AAA 7:1). Status colors on overlay-bg all exceed 4.5:1. |
| UX-03: Audio-first | No typing during active session. Voice commands for end session. Only tap interaction is stop button. |
| UX-04: Both orientations | SessionHUD repositions controls via orientation prop. Camera fills screen in both. |
| COMP-01: Non-dismissible AI indicator | AIIndicator has position: absolute, zIndex: 9999. No dismiss gesture. Rendered outside modal/dialog hierarchy. Visible in portrait, landscape, connecting, active, disconnected, reconnecting, failed, and timeout states. |
| COMP-02: AI disclosure | Blocks session start until "I Understand" is tapped. Cannot be bypassed or auto-dismissed. |
| accessibilityLabel | Stop button: "End session". AI indicator: "AI-assisted session active". Connection status: dynamic label matching visible text. |
| accessibilityRole | Stop button: "button". AI indicator: "text". Status: "text". |
