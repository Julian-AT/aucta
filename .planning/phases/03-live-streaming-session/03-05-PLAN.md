Simple hook that checks and requests camera + microphone permissions using Expo APIs.

```typescript
import { useCameraPermissions } from "expo-camera";
import { useEffect, useState } from "react";

export type PermissionStatus = "undetermined" | "granted" | "denied";

export function usePermissions() {
  const [cameraPermission, requestCamera] = useCameraPermissions();
  const [micPermission, setMicPermission] = useState<PermissionStatus>("undetermined");

  // For microphone, use Audio.requestPermissionsAsync() from expo-av
  // OR check via PermissionsAndroid on Android + Info.plist on iOS
  // Since react-native-audio-api handles mic access through AudioContext,
  // the permission prompt may happen automatically. Still, explicitly request upfront.

  async function requestAll(): Promise<{ camera: boolean; mic: boolean }> {
    const camResult = await requestCamera();
    // Mic permission: use expo-camera's requestMicrophonePermissionsAsync if available,
    // or platform-specific approach. expo-camera exposes useMicrophonePermissions.
    // Return { camera: camResult.granted, mic: micResult }
  }

  return {
    cameraGranted: cameraPermission?.granted ?? false,
    micGranted: micPermission === "granted",
    allGranted: (cameraPermission?.granted ?? false) && micPermission === "granted",
    requestAll,
    isChecking: !cameraPermission,
  };
}
```

The exact microphone permission API depends on what expo-camera or the platform provides. Expo SDK 55 has `useMicrophonePermissions` from expo-camera. Use that.

**Create apps/mobile/hooks/useBackgroundAudio.ts:**

Manages iOS background audio mode activation and Android foreground service notification.

```typescript
import { useEffect } from "react";
import { Platform, AppState } from "react-native";

export function useBackgroundAudio(isSessionActive: boolean) {
  useEffect(() => {
    if (!isSessionActive) return;

    if (Platform.OS === "android") {
      // Create foreground service notification via @notifee/react-native
      // Title: "Aucta AI Session" (per UI-SPEC copywriting)
      // Body: "AI session is active"
      // This keeps the audio pipeline alive when backgrounded (D-08)
      const startForegroundService = async () => {
        try {
          const notifee = await import("@notifee/react-native");
          const channelId = await notifee.default.createChannel({
            id: "session",
            name: "AI Session",
            importance: 3, // HIGH
          });
          await notifee.default.displayNotification({
            title: "Aucta AI Session",
            body: "AI session is active",
            android: {
              channelId,
              asForegroundService: true,
              ongoing: true,
            },
          });
        } catch {
          // Notifee may not be available in dev - log but don't crash
        }
      };
      startForegroundService();

      return () => {
        // Cancel foreground service on cleanup
        import("@notifee/react-native").then((notifee) => {
          notifee.default.cancelAllNotifications();
        }).catch(() => {});
      };
    }

    // iOS: background audio mode is configured in app.json (UIBackgroundModes: ["audio"])
    // No runtime code needed beyond keeping AudioContext alive
    return undefined;
  }, [isSessionActive]);
}
```

**Create apps/mobile/hooks/useGeminiSession.ts:**

The main orchestration hook. This is the brain of the session screen. It coordinates:
1. Token acquisition via tRPC
2. GeminiConnection lifecycle
3. Audio capture and playback
4. Frame capture
5. Tool call relay
6. Reconnection
7. Session cleanup

```typescript
import { useRef, useCallback, useEffect } from "react";
import { useTRPC } from "@/lib/api";
import { useMutation } from "@tanstack/react-query";
import { useSessionStore } from "@/stores/session-store";
import { GeminiConnection } from "@/lib/gemini/connection";
import { AudioPlayback } from "@/lib/gemini/audio-playback";
import { AudioCapture } from "@/lib/gemini/audio-capture";
import { FrameCapture } from "@/lib/gemini/frame-capture";
import { ToolRelay } from "@/lib/gemini/tool-relay";
import { reconnectWithBackoff } from "@/lib/gemini/reconnection";
import { activateKeepAwakeAsync, deactivateKeepAwake } from "expo-keep-awake";
import type { CameraView } from "expo-camera";

export function useGeminiSession(cameraRef: React.RefObject<CameraView>) {
  // ... refs, store, tRPC setup

  const startSession = useCallback(async () => {
    // 1. Set status to "connecting"
    // 2. Activate screen keep-awake (UX-05)
    // 3. Call trpc.session.createToken.mutate() to get { token, model, toolDeclarations }
    // 4. Create AudioPlayback, AudioCapture, ToolRelay instances
    // 5. Create GeminiConnection with callbacks:
    //    - onAudioData: playback.enqueueChunk(data) + store.setAISpeaking(true)
    //    - onToolCall: relay.relay(toolCall) then connection.sendToolResponse(result)
    //    - onTurnComplete: store.setAISpeaking(false)
    //    - onResumptionUpdate: store.setResumptionHandle(handle)
    //    - onGoAway: warn about session ending soon
    //    - onSetupComplete: store.setStatus("active") + start audio capture + start frame capture
    //    - onDisconnect: trigger reconnection flow
    //    - onError: store.setError(msg)
    // 6. Connect to Gemini
  }, []);

  const endSession = useCallback(() => {
    // 1. Stop frame capture
    // 2. Stop audio capture
    // 3. Close connection
    // 4. Destroy audio playback
    // 5. Deactivate keep-awake
    // 6. Set status to "completed"
    // 7. Reset store
  }, []);

  // Cleanup on unmount
  useEffect(() => {
    return () => { /* cleanup all resources */ };
  }, []);

  return {
    startSession,
    endSession,
    // Store selectors exposed for SessionScreen
    status: useSessionStore((s) => s.status),
    connectionQuality: useSessionStore((s) => s.connectionQuality),
    isAISpeaking: useSessionStore((s) => s.isAISpeaking),
    error: useSessionStore((s) => s.error),
  };
}
```

Key orchestration details:

**Token acquisition:** Use tRPC mutation via `useTRPC().session.createToken` + `useMutation`. On success, proceed to WebSocket connection. On failure, set status to "failed" with error.

**onSetupComplete callback:** This fires when Gemini acknowledges the setup message. At this point:
- Set store status to "active"
- Start AudioCapture (mic becomes hot per D-05)
- Start FrameCapture (camera begins streaming at 1 FPS)
- Set store.setMicActive(true)

**onAudioData callback:** Enqueue audio chunk for playback. Set isAISpeaking = true. This drives the AudioIndicator animation.

**onDisconnect callback:** Trigger reconnection:
- Set status to "reconnecting"
- Call reconnectWithBackoff with connect function that re-creates WebSocket using stored resumptionHandle
- On reconnect success: set status back to "active", restart audio/frame capture
- On give-up: set status to "timeout"

**Tool call flow (COMP-06 verification):** Tool calls arrive over WebSocket -> relay to server via tRPC (structured JSON only) -> server dispatches tool -> result returns -> send toolResponse back to Gemini. NO audio/video data passes through our server. Audio/video goes directly mobile -> Gemini WebSocket.

**expo-keep-awake (UX-05):** Call `activateKeepAwakeAsync()` when session starts. Call `deactivateKeepAwake()` when session ends. Prevents screen dimming during active session.

Props: none (self-contained screen component).

**State management:**
- Local state: `showEndDialog` (boolean), `disclosureAccepted` (boolean)
- Store state via useGeminiSession: status, connectionQuality, isAISpeaking, error

**Lifecycle (per UI-SPEC State-Driven UI Matrix + Interaction Contracts):**

1. **Mount:** Check permissions via usePermissions. Set store status to "requesting-permissions". If permissions not granted, show system dialog. If denied, show error message with link to settings.

2. **Permissions granted:** Set store status to "disclosure". Show AIDisclosureModal.

3. **Disclosure accepted:** Set `disclosureAccepted = true`. Start session via `useGeminiSession.startSession()`. This sets status to "connecting" and activates camera.

4. **Connecting:** Camera fills screen (CameraView with `style={{ flex: 1 }}`). SessionHUD shows with amber "Connecting..." status. Stop button visible.

5. **Active:** Green "Connected". Audio indicator visible. Camera streaming. Mic hot.

6. **Stop button press:** Show EndSessionDialog. On confirm: call endSession(), navigate to Home via `router.replace("/(app)/(tabs)")`. On cancel: dismiss dialog.

7. **Reconnecting:** Yellow "Reconnecting..." with animation. Camera stays live. Audio pauses.

8. **Failed/Timeout:** ConnectionLostOverlay appears. "Start New Session" button navigates back to Home.

**Camera rendering:**
- CameraView with `facing="back"` (rear camera for equipment)
- `style={{ position: 'absolute', top: 0, left: 0, right: 0, bottom: 0 }}` for full screen
- `ref={cameraRef}` passed to useGeminiSession for frame capture

**Orientation detection:**
- Use `useWindowDimensions()` to detect: `width > height ? "landscape" : "portrait"`
- Pass to SessionHUD orientation prop

**Background audio activation:**
- Call `useBackgroundAudio(status === "active" || status === "connecting" || status === "reconnecting")`
