<objective>
Build the Gemini Live WebSocket connection manager and reconnection logic. The GeminiConnection class handles the full WebSocket lifecycle: connecting with the correct setup message (including SlidingWindow context compression and sessionResumption), parsing all incoming server messages into typed callbacks, and sending audio/video/tool response data. The reconnection module implements exponential backoff with jitter and a 2-minute give-up threshold.

Purpose: This is the communication backbone of the real-time session. All audio, video, and tool data flows through the GeminiConnection. Reconnection ensures resilience for field technicians working in areas with intermittent connectivity.

Output: GeminiConnection class, reconnection utilities, comprehensive tests for both.

**Create apps/mobile/lib/gemini/connection.ts:**

The GeminiConnection class manages a single WebSocket connection to Gemini Live. It uses constructor injection for all callbacks (dependency injection pattern per project rules).

```typescript
export interface GeminiConnectionDeps {
  onAudioData: (pcmBase64: string) => void;
  onToolCall: (toolCall: { functionCalls: Array<{ id: string; name: string; args: Record<string, unknown> }> }) => void;
  onTurnComplete: () => void;
  onResumptionUpdate: (handle: string) => void;
  onGoAway: (timeLeft: string | undefined) => void;
  onSetupComplete: () => void;
  onDisconnect: (code: number, reason: string) => void;
  onError: (error: string) => void;
}

export interface GeminiConnectionConfig {
  token: string;
  model: string;
  toolDeclarations?: Array<{ name: string; description: string; parameters: Record<string, unknown> }>;
  resumptionHandle?: string | null;
}
```

Key implementation details:
- **Constructor:** Accepts `GeminiConnectionDeps` via constructor injection. Stores deps as private readonly field.
- **connect(config: GeminiConnectionConfig):** Creates `new WebSocket(GEMINI_WS_URL + "?access_token=" + config.token)`. On open, sends setup message JSON. On message, parses with `JSON.parse` and dispatches using type guards from protocol.ts (`isServerContent`, `isToolCall`, etc.).
- **Setup message:** Always includes `responseModalities: ["AUDIO"]`, `contextWindowCompression: { slidingWindow: {} }` (per SESS-07), and `model: "models/" + config.model`. If `config.resumptionHandle` is truthy, include `sessionResumption: { handle: config.resumptionHandle }`. Otherwise include `sessionResumption: {}` (empty object signals first connect). If `config.toolDeclarations` exists, include `tools: [{ functionDeclarations: config.toolDeclarations }]`.
- **Message handling (onmessage):** Parse JSON. Use type guards sequentially:
  1. `isSetupComplete` -> call `deps.onSetupComplete()`
  2. `isServerContent` -> if `modelTurn?.parts`, iterate parts, for each `inlineData?.data` call `deps.onAudioData(data)`. If `turnComplete` is true, call `deps.onTurnComplete()`.
  3. `isToolCall` -> call `deps.onToolCall(msg.toolCall)`
  4. `isSessionResumptionUpdate` -> if `resumable && newHandle`, call `deps.onResumptionUpdate(newHandle)`
  5. `isGoAway` -> call `deps.onGoAway(msg.goAway.timeLeft)`
- **sendAudio(pcmBase64: string):** Guard `ws?.readyState === WebSocket.OPEN`. Send `JSON.stringify({ realtimeInput: { audio: { data: pcmBase64, mimeType: AUDIO_INPUT_MIME } } })`.
- **sendVideo(jpegBase64: string):** Guard readyState. Send `{ realtimeInput: { video: { data: jpegBase64, mimeType: "image/jpeg" } } }`.
- **sendToolResponse(functionResponses):** Guard readyState. Send `{ toolResponse: { functionResponses } }`.
- **close():** If ws exists and readyState is OPEN or CONNECTING, call `ws.close(1000, "client-close")`. Set ws to null.
- **isConnected():** Returns `ws?.readyState === WebSocket.OPEN`.
- **onclose handler:** If close code is not 1000 (normal) and not caused by client-initiated close(), call `deps.onDisconnect(code, reason)`.
- **onerror handler:** Call `deps.onError(event.message ?? "WebSocket error")`.

Use a private `_intentionalClose` boolean flag to distinguish client-initiated close from unexpected disconnects.

**Create apps/mobile/lib/gemini/reconnection.ts:**

Two exported functions:

1. **calculateBackoff(attempt: number): number**
   Formula: `Math.min(BACKOFF_MAX_MS, BACKOFF_BASE_MS * Math.pow(2, attempt)) + Math.random() * BACKOFF_JITTER_MS`
   Uses constants from protocol.ts: BACKOFF_BASE_MS (1000), BACKOFF_MAX_MS (30000), BACKOFF_JITTER_MS (500).

2. **reconnectWithBackoff(deps: ReconnectDeps): Promise\<void\>**
   ```typescript
   export interface ReconnectDeps {
     connect: () => Promise<boolean>;
     onSuccess: () => void;
     onGiveUp: () => void;
     getSessionStore: () => {
       setConnectionQuality: (q: ConnectionQuality) => void;
     };
   }
   ```

   Implementation:
   - Record `startTime = Date.now()`
   - Enter while loop: `while (Date.now() - startTime < RECONNECT_TIMEOUT_MS)`
   - Calculate delay with `calculateBackoff(attempt)`
   - `await new Promise(resolve => setTimeout(resolve, delay))`
   - Call `deps.getSessionStore().setConnectionQuality("reconnecting")`
   - `const success = await deps.connect()`
   - If success: call `deps.onSuccess()`, return
   - Increment attempt counter
   - After loop exits (2 minutes elapsed): call `deps.getSessionStore().setConnectionQuality("lost")`, then `deps.onGiveUp()`
