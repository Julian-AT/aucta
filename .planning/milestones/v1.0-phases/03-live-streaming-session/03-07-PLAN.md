In the `buildConnectionDeps` callback, modify the `onToolCall` handler to intercept the endSession tool before relaying to the server:

```typescript
onToolCall: async (toolCall) => {
  // Check for client-side endSession tool (SESS-09, D-12)
  const endSessionCall = toolCall.functionCalls.find(
    (fc) => fc.name === "endSession",
  );

  if (endSessionCall) {
    // Send success response back to Gemini so it can speak the goodbye
    connectionRef.current?.sendToolResponse([
      {
        id: endSessionCall.id,
        name: "endSession",
        response: { success: true },
      },
    ]);

    // Wait briefly for Gemini to speak "Ending the session now. Goodbye."
    // then end the session. The 3-second delay allows the verbal confirmation
    // to play before cleanup stops audio.
    setTimeout(() => {
      endSessionRef.current?.();
    }, 3000);
    return;
  }

  // Relay all other tool calls to server
  if (!toolRelayRef.current || !connectionRef.current) return;
  const result = await toolRelayRef.current.relay(toolCall);
  connectionRef.current.sendToolResponse(result.functionResponses);
},
```

Replace the current `takePictureAsync` block inside the setInterval callback with a version that resizes:

```typescript
this.isCapturing = true;
try {
  const photo = await this.deps.cameraRef.current.takePictureAsync({
    quality: JPEG_QUALITY,
    // Note: base64 NOT requested here -- expo-image-manipulator
    // will produce base64 from the resized image instead.
  });
  if (photo?.uri) {
    // Resize to max 768px on longest dimension (SESS-02)
    const resizeAction =
      photo.width >= photo.height
        ? { resize: { width: FRAME_MAX_DIMENSION } }
        : { resize: { height: FRAME_MAX_DIMENSION } };

    const resized = await manipulateAsync(
      photo.uri,
      [resizeAction],
      { base64: true, format: SaveFormat.JPEG, compress: JPEG_QUALITY },
    );

    if (resized.base64) {
      this.deps.onFrame(resized.base64);
    }
  }
} catch {
  // Camera may be paused when app is backgrounded (D-08), skip frame silently
} finally {
  this.isCapturing = false;
}
```

Key changes from current implementation:
- `takePictureAsync` no longer requests `base64: true` (saves encoding full-res image)
- After capture, `manipulateAsync` resizes to 768px on longest dimension
- The resize action picks width or height based on which is larger (landscape vs portrait)
- `SaveFormat.JPEG` with `compress: JPEG_QUALITY` (0.6) produces the final base64
