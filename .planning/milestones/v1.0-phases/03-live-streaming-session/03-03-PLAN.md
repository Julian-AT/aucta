**Create apps/mobile/lib/gemini/audio-playback.ts:**

The AudioPlayback class plays back Gemini's 24kHz PCM audio response stream using the Web Audio API pattern from react-native-audio-api. It schedules sequential AudioBufferSourceNode instances for gapless playback.

```typescript
import { AudioContext } from "react-native-audio-api";
import { AUDIO_OUTPUT_SAMPLE_RATE } from "./protocol";

export class AudioPlayback {
  private ctx: AudioContext;
  private nextStartTime: number;

  constructor() {
    this.ctx = new AudioContext({ sampleRate: AUDIO_OUTPUT_SAMPLE_RATE });
    this.nextStartTime = this.ctx.currentTime;
  }

  enqueueChunk(pcmBase64: string): void { ... }
  interrupt(): void { ... }
  destroy(): void { ... }
}
```

**enqueueChunk(pcmBase64):**
1. Decode base64 to bytes. Use `atob()` (available in RN 0.83) to decode, then create a Uint8Array from the char codes.
2. Convert 16-bit PCM (little-endian signed integers) to Float32Array: iterate pairs of bytes, reconstruct Int16 with `(byte2 << 8) | byte1` (handling sign extension for values > 32767), divide by 32768.0 to get -1.0..1.0 range.
3. Create AudioBuffer: `ctx.createBuffer(1, float32.length, AUDIO_OUTPUT_SAMPLE_RATE)`
4. Copy data: `buffer.copyToChannel(float32, 0)`
5. Create source: `ctx.createBufferSource()`, set `source.buffer = buffer`, `source.connect(ctx.destination)`
6. Schedule: `const startTime = Math.max(this.nextStartTime, this.ctx.currentTime)`, `source.start(startTime)`
7. Update: `this.nextStartTime = startTime + buffer.duration`

**interrupt():**
On barge-in (D-07), stop all scheduled audio immediately. Close existing AudioContext (`this.ctx.close()`), create fresh AudioContext, reset nextStartTime to new context's currentTime. This cancels all pre-scheduled AudioBufferSourceNode instances.

**destroy():**
Close AudioContext. Called on session end.

**Helper functions (private or module-level):**
- `base64ToUint8Array(base64: string): Uint8Array` -- atob + charCodeAt loop
- `pcm16ToFloat32(pcmBytes: Uint8Array): Float32Array` -- little-endian Int16 to float conversion

```typescript
  destroy(): void { ... }

```

**start():**

**Create apps/mobile/lib/gemini/frame-capture.ts:**

The FrameCapture class captures JPEG frames from the expo-camera CameraView ref at 1 FPS. It includes a guard flag to prevent concurrent captures (pitfall #2 from research).

```typescript
import type { CameraView } from "expo-camera";
import { CAPTURE_INTERVAL_MS, JPEG_QUALITY } from "./protocol";

export interface FrameCaptureDeps {
  cameraRef: React.RefObject<CameraView>;
  onFrame: (jpegBase64: string) => void;
}

export class FrameCapture {
  private intervalId: ReturnType<typeof setInterval> | null = null;
  private isCapturing = false; // Guard against concurrent captures

  constructor(private deps: FrameCaptureDeps) {}

  start(): void { ... }
  stop(): void { ... }
}
```

**start():**
1. Set up `setInterval` at `CAPTURE_INTERVAL_MS` (1000ms)
2. In the interval callback:
   a. If `this.isCapturing` or `!this.deps.cameraRef.current`, return (skip frame)
   b. Set `this.isCapturing = true`
   c. Try: `const photo = await this.deps.cameraRef.current.takePictureAsync({ base64: true, quality: JPEG_QUALITY })`
   d. If `photo?.base64`: call `this.deps.onFrame(photo.base64)`
   e. Catch: silently skip (camera may be paused when app is backgrounded per D-08)
   f. Finally: `this.isCapturing = false`
3. Store intervalId

**stop():**
Clear interval, set intervalId to null.

**Create apps/mobile/lib/gemini/tool-relay.ts:**

The ToolRelay forwards Gemini tool calls to the server via tRPC and returns responses. This is what makes tool calls work without interrupting the audio stream (SESS-06). Only structured JSON data flows through our server -- no audio/video (COMP-06).

```typescript
export interface ToolRelayDeps {
  dispatchToolCalls: (input: {
    functionCalls: Array<{ id: string; name: string; args: Record<string, unknown> }>;
  }) => Promise<{
    functionResponses: Array<{ id: string; name: string; response: Record<string, unknown> }>;
  }>;
}

export class ToolRelay {
  constructor(private deps: ToolRelayDeps) {}

  async relay(toolCall: {
    functionCalls: Array<{ id: string; name: string; args: Record<string, unknown> }>;
  }): Promise<{
    functionResponses: Array<{ id: string; name: string; response: Record<string, unknown> }>;
  }> { ... }
}
```

**relay():**
1. Try: `return await this.deps.dispatchToolCalls({ functionCalls: toolCall.functionCalls })`
2. Catch: map each functionCall to an error response: `{ id: fc.id, name: fc.name, response: { error: "Tool execution failed", code: "RELAY_ERROR" } }`. Return `{ functionResponses: errorResponses }`.

The `deps.dispatchToolCalls` will be wired to `trpcClient.session.dispatchToolCalls.mutate` in the orchestration hook (Plan 05). By injecting it as a dependency, the ToolRelay is testable without a real tRPC client.
