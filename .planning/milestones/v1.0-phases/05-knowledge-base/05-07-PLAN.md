    **Step 2: Add submitReview endpoint**

    Add to the router object (after the `healthCheck` endpoint):
    ```typescript
    submitReview: orgProcedure
      .use(errorConverter)
      .input(
        z.object({
          articleId: z.string(),
          status: z.enum(["approved", "rejected", "needs_revision"]),
          reviewerNotes: z.string().optional(),
        }),
      )
      .mutation(async ({ ctx, input }) => {
        // Verify article exists and belongs to this org
        const article = await articleRepo.findById(input.articleId);
        if (!article) {
          throw new TRPCError({
            code: "NOT_FOUND",
            message: `Article ${input.articleId} not found`,
          });
        }
        if (article.orgId !== ctx.orgId) {
          throw new TRPCError({
            code: "FORBIDDEN",
            message: "Cross-org access denied",
          });
        }

        // Create verification record
        const verification = await verificationRepo.create({
          articleId: input.articleId,
          orgId: ctx.orgId,
          reviewerId: ctx.userId,
          status: input.status,
          reviewerNotes: input.reviewerNotes,
        });

        // If approved, promote article confidence level
        if (input.status === "approved") {
          const newLevel = article.confidenceLevel === "unverified"
            ? "technician_reviewed"
            : article.confidenceLevel === "technician_reviewed"
              ? "expert_approved"
              : article.confidenceLevel;

          if (newLevel !== article.confidenceLevel) {
            const updated = await articleRepo.update(article.id, {
              confidenceLevel: newLevel,
            });
            // Re-embed with updated confidence level in Qdrant payload
            await embedAndUpsert(updated);
          }
        }

        return verification;
      }),
    ```

    The confidence promotion follows a ladder: unverified -> technician_reviewed -> expert_approved. manufacturer_sourced is only set manually (never auto-promoted). Each approval moves the article up one tier.
